# z.ai adapter fixtures

These redacted fixtures cover the monitor response used by the z.ai GLM
Coding Plan usage-query tooling. `normal.json` and `multiple_windows.json`
use the current `CREDIT_LIMIT` shape; `legacy_tokens.json` preserves the
older `TOKENS_LIMIT` shape and includes the optional monthly `TIME_LIMIT`
request row. No API key, token, cookie, or account identifier is included.
